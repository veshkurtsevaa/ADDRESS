# ADDRESS

Статический двуязычный сайт (RU/EN) о кураторских путешествиях.

**Живой сайт:** https://addressguides.com

## Как это устроено

Чистые HTML, CSS и JS, без сборщика. Четыре страницы: `index.html` (главная),
`about.html`, `service.html`, `contacts.html`. Тексты обоих языков живут в
`i18n.js`, в HTML лежит английский вариант как значение по умолчанию.

Правила для текстов на сайте (точки, тире, неразрывные пробелы) описаны
в `CLAUDE.md`. Фотографии и их назначение перечислены в `assets/img/README.md`.
Неиспользуемые исходники лежат в `assets/_src/`, референсы и архивное
техническое задание в `docs/`.

## Публикация

Сайт работает на Cloudflare, домен `addressguides.com`. Как именно он
публикуется сейчас и что делать после мержа в `main`, описано в разделе
«Деплой» в `CLAUDE.md`.

Ссылки на стили и скрипты в HTML снабжены номером версии (`styles.css?v=37`),
который нужно увеличивать при правках, иначе браузеры отдают старый файл
из кэша.
